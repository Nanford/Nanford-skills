# AI 自媒体视频生产工作流

面向 AI 实战类视频号、抖音内容，采用「选题与核验 → 视频文案 → 配音稿 → 配音与时间轴 → 素材剪辑 / Remotion 画面 → 配乐与字幕 → 质检 → 按指定平台交付（默认抖音） → 数据复盘」的生产流程。

**主路线：真实录屏与结果展示为主，Remotion 动画负责解释，AI 生图与生视频补充必要场景。**

## 直接使用

在此目录启动 Claude Code 或 Codex CLI（两者读取同一份 `AGENTS.md`，不使用 n8n 等可视化编排器），提供主题、文章或素材路径。首次用于生产时，先执行环境检查及最小链路建设；后续从项目状态记录继续。

**基础搭建指令**

> 按 AGENTS.md 和 WORKFLOW.md 搭建本地最小生产链路。先支持导入真人配音、已有录屏、Remotion 动画、字幕、配乐和 MP4 导出，再接入正式 TTS。完成验收标准中的测试并记录真实结果。未授权的付费调用先保留为待接入项。

**从选题生产**

> 主题是「把一份会议记录整理成可核对的行动清单」。受众是办公室职员。制作抖音 60～120 秒版、视频号 60～180 秒版，采用真实录屏与 Remotion 混合画面。先检查现有素材和工具，按 AGENTS.md 推进到可交付成片；缺少关键实测材料时明确记录，成片不自动发布。

**从公众号内容改编**

> 改编素材库（`videocut.workspace.json` 的 `article_library`）里的 `<文章名>.md`，视频要讲的问题是「……」。保留原文事实来源，重新核验时效信息，使用视频口语表达，不直接朗读文章。

**从参考素材剪辑**

> 使用 inbox 中我有使用权的录屏和视频，先建立带时间码的素材索引，再围绕选题形成文案和配音。优先使用能证明内容的片段，不足部分使用明确标注的原理动画。保留素材入点、出点及剪辑工程。

**修改与复盘**

> 保留已通过验收的配音和事实依据，只修改开头、字幕或指定镜头；重跑受影响的步骤。使用我提供的后台数据，对同平台、同口径、近似时长的内容进行复盘，输出下一轮可检验的内容假设。
