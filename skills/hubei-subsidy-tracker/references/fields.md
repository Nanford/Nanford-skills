# 三张表字段规范（本地 Excel / 飞书多维表格 / 钉钉 AI 表格）

> 文本类→文本；省·市/政策类别/处理状态/匹配结论→单选；关键词标签/资质/人才类型→多选；日期→日期；原文链接→URL。系统双写按去重键 upsert，**不覆盖**协作平台中人工已填列。钉钉记录写入使用实际 fieldId，政策附件使用 attachment 字段。

## 5.3 匹配结果表 `match_results.xlsx`（政策 × 企业）
| 字段 | 含义 | 示例 |
|---|---|---|
| 政策ID | 关联政策清单(序号) | 12 |
| 企业名称 | 关联档案表 | 武汉某某智能科技 |
| 匹配结论 | 匹配 / 部分匹配 / 信息不足 / 待人工 / 不匹配 / 无需匹配 | 部分匹配 |
| 命中条件 | 已满足的门槛 | 高企、营收达标 |

| 通知状态 | 已推送 / 未推送 | 未推送 |
| 处理状态 | 待申报 / 已申报 / 放弃 | 待申报 |
