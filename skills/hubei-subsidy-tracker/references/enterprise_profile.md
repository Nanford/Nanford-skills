# 企业档案字段模板与示例（阶段3）

> 在飞书新建多维表格（或用本地 `enterprises.xlsx`），**每行一个企业**，字段如下。敏感字段（纳税/利润、研发费用等）上飞书后设可见范围（仅政策管理员 + 申报负责人）。

## 字段与类型
| 字段 | 飞书类型 | 说明 |
|---|---|---|
| 企业名称 | 单行文本（主键） | 用于匹配去重 |
| 统一信用代码 | 单行文本 | — |
| 行业 | 单选 | 智能制造 / 软件 / 电子信息 / 其他 |
| 规模-营收 | 单行文本 | 如"年营收5000万" |
| 规模-人数 | 数字 | 如 120 |
| 资质 | 多选 | 高企 / 专精特新 / 单项冠军 / 瞪羚 / 科技型中小企业 / 规上 |
| 近一年营收 | 数字（万） | 用于软门槛比较 |
| 纳税/利润 | 单行文本 | 如"纳税200万" |
| 研发费用 | 数字（万） | 用于软门槛比较 |
| 社保人数 | 数字 | 用于软门槛比较 |
| 人才类型 | 多选 | 博士 / 硕士 / 海归 / 高工 / 技能人才 / 博士后 |
| 注册地区 | 单选 | 东湖高新 / 江岸 / 武汉其他区 / 湖北省其他市 |
| 通知人 | 单行文本 | 该企业的对应操作人；钉钉模式按姓名映射 userId 后单聊，不设置固定或默认收件人 |
| 备注 | 多行文本 | — |

## 示例行
| 企业名称 | 行业 | 规模-人数 | 资质 | 近一年营收 | 研发费用 | 社保人数 | 人才类型 | 注册地区 | 通知人 |
|---|---|---|---|---|---|---|---|---|---|
| 武汉某某智能科技有限公司 | 智能制造 | 120 | 高企、专精特新 | 5000 | 400 | 110 | 博士、海归 | 东湖高新 | 张三@武汉某某 |

## 录入建议
- 先录 1 家做端到端验证（阶段4 匹配 → 阶段5 草稿 → 阶段6 通知）。
- 资质/人才类型用**规范枚举值**，匹配引擎按 `match_engine.py` 的 `QUAL_MAP` 识别。
- 数值字段（营收/研发费用/社保人数）填纯数字（万），便于软门槛自动比较。
