# 湖北惠企政策助手

客户以自然语言提出需求，智能体负责检查环境、维护进度、调用脚本和核验结果。客户只处理业务选择、资料确认及必要授权。

## 入口与流程选择

1. 定位本 Skill 的绝对路径。所有脚本从该路径执行，不依赖对话工作目录。最低 Python 版本为 3.10；先探测解释器，缺失时引导安装，不假设任意宿主都能执行本地代码。
2. 首次调用先运行 `python scripts/init_setup.py --status --json`。退出码 2 表示存在待完成项，也可能是配置错误；结合 JSON 或错误信息处理，不能直接解释为安装失败。
3. 按实际意图选择流程，已具备的能力可以先使用，未启用的可选功能不阻塞查询：

| 意图 | 执行路径 |
|---|---|
| 开始使用、安装、配置、继续上次配置 | 读取 [首次引导](references/onboarding.md)，执行当前 `next_action` |
| 今日政策、企业能报什么、更新档案 | 读取 [日常运行](references/operations.md)，使用已验证能力 |
| 没收到通知、任务失败、迁移后不能运行 | 读取 [恢复流程](references/recovery.md)，核对证据并从失败步骤继续 |
| 选择千问办公与钉钉 | 额外读取 [钉钉接入](references/dingtalk_qwen.md) |
| 生成申报核对草稿 | 运行 `fill_draft.py`，列出已知信息、资料缺口与原文入口 |

4. 执行一步后重新检查状态；需要保存进度时添加 `--checkpoint`。只呈现当前步骤的结果及下一项客户操作，避免一次列出全部配置事项。

## 首次使用体验

- 自动检查当前宿主是否支持本地执行、平台连接器与定时任务。根据实际能力推荐使用方式，保留客户已有选择；不把三套平台配置同时交给客户。
- 新安装默认本地模式。已选飞书或钉钉时直接继续该模式。重复安装保留原模式、企业资料和凭证。
- 企业名称、注册地区、主营行业用于首次初筛。资质、营收、研发、社保等资料按政策门槛逐步补充；未知值留空，不填零，不推断资质。
- 已有资料先识别并交客户核对；已有表格先检查结构再绑定。不重复建表，不猜同名人员，不用默认收件人。
- 通知与定时任务默认未启用。客户确定范围后保存偏好；开启通知先预览当前有效存量匹配结果与收件人，再做受控测试。一次明确授权在原范围内持续有效，目标或影响范围变化时重新核对。
- 客户说“继续”时，从实际未完成项恢复，不重新询问已有信息。

## 能力与边界

- 采集范围为湖北省、武汉市经信、科技、财政、人社等 8 个官方来源，详见 [渠道](references/channels.md)。当前不承诺覆盖全部省市区政策。
- 从正文抽取门槛、支持额度、申报对象与截止日期，保留原文与可下载附件。附件未完成条款级解析时进入复核，不声称完成附件回填或完整资格审查。
- 企业匹配输出“匹配、部分匹配、信息不足、待人工、不匹配”；结果公示等不适用内容不进入通知。匹配表示已识别条件满足，不代表审核通过或必然获补贴。
- 飞书通知是配置群内的汇总播报，适用于有权查看相应企业信息的团队；不承诺企业负责人单聊隔离。千问办公钉钉按企业负责人映射执行个人通知。
- 查询、匹配、通知、定时分别报告验证状态。配置文件存在、安装命令结束、任务已创建均不能证明业务全链路成功。
- 申报草稿只核对已知企业字段与资料清单；最终由负责人审核并提交。不得代填未知经营数据。

## 数据与重复运行

- 默认数据目录为 Skill 下的 `data/`；可通过 `SUBSIDY_DATA_DIR` 指定独立客户目录，通过 `SUBSIDY_CONFIG_FILE` 指定独立配置文件。智能体在本轮所有脚本调用中沿用相同绝对路径；多客户分别隔离目录、配置与任务。
- `setup_state.json` 保存偏好与验证回执，`setup_report.json` 保存当前待办，`last_run.json` 保存日常任务结果。回执绑定配置或输入摘要，相关数据变化后需要重新核验。
- `subsidy_records.xlsx`、`enterprises.xlsx`、`match_results.xlsx` 分别存政策、企业、匹配结果；字段规范见 [字段](references/fields.md) 和 [企业档案](references/enterprise_profile.md)。
- `notifications.sqlite` 保存发送预留与成功记录。成功通知不自动重置；结果不明的发送先核对再恢复。日报仅统计当天新增，通知覆盖当前有效且尚未成功发送的匹配，包括隔天补档后的机会。
- 本地、飞书日常运行入口为 `scripts/run_daily.py`。钉钉外部操作只能由具备相应能力的千问办公宿主执行；Windows 后台不代替宿主连接器。
- 不删除已有企业资料、不覆盖人工处理列。Word/Excel 占用时保留原文件并报告，避免强制覆盖。

## 结果呈现

政策结果包含政策名称、支持方向、已核验额度与截止日期、企业匹配依据、未确认条件、下一步行动、负责人和原文链接。不存在的金额或日期不编造。

采集源失败时明确说明结果不完整；零命中提示核对源页面。无新增不等于采集正常。通知结果不明时报告待核对数量，不宣称发送成功。

分发包由 `scripts/package_skill.ps1` 生成，仅包含程序、引用说明与配置模板，不含企业资料、凭证、运行记录或本机任务入口。
