# 类目观察重点

读图时按类目决定看什么。类目判断错误会让整份卖点偏离方向，所以先定类目再提炼。
未覆盖的类目，选最接近的一条使用，并在输出中说明。

## apparel 服饰穿戴

重点观察面料质感与纹理、版型剪裁、缝线与走线工艺、领口袖口等细节处理、配色与图案、可搭配场景。

卖点结构通常是：面料舒适性 → 版型显瘦或修饰效果 → 适用场景与季节 → 尺码与洗涤 → 配色选择。

必须标待确认的：面料成分比例、克重、尺码对应体重身高、是否可机洗。这些猜错会直接导致退货。

## 3c-accessory 3C 与电子配件

重点观察接口类型与数量、指示灯与按键、外壳材质与散热结构、线材粗细与接头工艺、随附配件。

卖点结构通常是：核心性能参数 → 兼容机型范围 → 安全保护机制 → 便携性或收纳 → 质保与售后。

必须标待确认的：功率、容量、传输速率、协议版本、认证资质、兼容机型清单。这一类是投诉重灾区，宁可让用户补充也不要推测。

## home 家居家纺

重点观察材质与触感、尺寸与空间占用、组装结构、收纳方式、配色与风格倾向、与家居环境的适配。

卖点结构通常是：解决什么空间问题 → 材质与耐用性 → 尺寸适配说明 → 安装或使用便利 → 风格搭配。

必须标待确认的：具体尺寸、承重、材质环保等级、是否需要工具组装。

## kitchen 厨房用品

重点观察接触食物的材质、耐温表现、把手与防烫设计、清洁便利性、容量与规格、是否适配炉具类型。

必须标待确认的：材质食品级认证、耐温范围、容量、是否可洗碗机、是否适配电磁炉。

## beauty 美妆个护

重点观察包装形态、质地与色号、使用部位、便携性。

这个类目对功效表述极其敏感，欧美站尤甚。提炼卖点时避开一切疗效暗示，只写使用体验、质地、包装与场景。成分、功效、适用肤质一律标待确认，且下游会有额外的禁用词拦截。

## baby 母婴用品

重点观察材质安全性、边角处理、尺寸与适用月龄、清洁方式、安全结构设计。

安全相关的一切表述都要有依据。适用月龄、材质安全认证、承重、是否含 BPA 等，全部标待确认。这个类目的合规风险最高。

## outdoor 户外运动

重点观察材质与防护性能、重量与收纳体积、结构与连接方式、适用环境、配件完整度。

必须标待确认的：防水等级、承重、耐温范围、净重、展开与收纳尺寸。

## pet 宠物用品

重点观察适用宠物体型、材质耐咬性与安全性、清洁方式、尺寸规格、结构稳定性。

必须标待确认的：适用体重范围、材质安全性、尺寸。

## tools 工具五金

重点观察材质与镀层、握持部位设计、规格标识、配件与收纳、适用作业场景。

必须标待确认的：规格尺寸、扭矩或功率、适配标准、材质硬度。
