# eBay 站点规则

核对日期：2026-08-01（初始种子值，上线前对照 eBay 卖家中心校准）

eBay 整体比 Amazon 宽松，但标题长度短很多，这是文案生成时最需要注意的差异。

## 图片规格

主图最长边不低于 500 像素，推荐 1600 像素以上以支持缩放。图片数量通常最多 24 张，远多于 Amazon，可以更充分展示细节和场景。

eBay 对主图的限制比 Amazon 松，允许非纯白背景，但不允许边框、水印、卖家 logo 和促销文字。实务上仍建议主图用白底，因为搜索结果页的视觉一致性影响点击。

## 文案规格

| 字段 | 限制 | 说明 |
|------|------|------|
| 标题 | 80 字符 | 与 Amazon 最大的差异，标题必须重写而非截断 |
| 副标题 | 55 字符，付费功能 | 可选 |
| 描述 | 支持 HTML | 移动端占比高，避免复杂排版 |
| Item Specifics | 结构化属性 | 对搜索曝光影响大，尽量填全 |

eBay 没有 Amazon 那样的独立五点描述字段。用户在 eBay 场景下要五点描述时可以生成，但要说明这是描述正文的一部分。

标题 80 字符意味着不能照搬 Amazon 标题。重写策略是保留核心产品词加最重要的两到三个属性，砍掉长尾修饰。

## 禁用与风险表述

不得在标题中堆砌不相关关键词。不得出现其他平台名称或站外联系方式。不得引导站外交易。品牌词使用要与实际商品一致。

## 导出字段映射

File Exchange 常用字段：

CustomLabel, Title, Subtitle, Description, PicURL（多图竖线分隔）, Category, ConditionID, 以及 C:Brand 等 Item Specifics 列
