### 3.2 金额书写防错（修正规则一旦触发只能被动接受）

| 规则 | 核对 |
|---|---|
| 大写与小写金额一致 | ☐ |
| 单价 × 数量 = 分项合计 | ☐ |
| 分项合计 = 总价 | ☐ |
| 报价表、响应函、汇总表三处金额一致 | ☐ |
| 已加盖电子印章 | ☐ |
| 提交时间早于截止时间（预留 ≥2 小时） | ☐ |

> 修正顺序：大写与小写不一致→以**大写**为准；总价与单价汇总不一致→以**单价汇总**为准；两种以上不一致→按此顺序依次修正。修正后需我方确认，不确认作无效响应。
