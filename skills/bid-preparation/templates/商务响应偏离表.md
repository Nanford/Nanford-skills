# 商务响应偏离表模板

> **使用说明**: 从招标文件第二章（投标人须知）中提取所有商务条款，逐条填写响应状态。不允许有空项。

---

## 格式

| 序号 | 招标文件条款 | 招标要求 | 投标响应 | 偏离说明 | 备注 |
|------|-------------|----------|----------|----------|------|
| 1 | 第二章X条 | [原文商务条款] | 完全响应/正偏离/负偏离 | 无偏离 | |
| 2 | 第二章X条 | [原文商务条款] | | | |
| ... | | | | | |

## 状态标注规范

| 状态 | 含义 | 使用场景 |
|------|------|----------|
| 无偏离 | 完全响应 | 满足招标要求（最常用） |
| 正偏离 | 优于招标要求 | 提供的条件比招标要求更好 |
| 负偏离 | 不满足招标要求 | **避免使用**，可能导致废标 |

## 常见商务条款类型

需要列入偏离表的商务条款包括但不限于：
- 投标有效期
- 投标保证金
- 履约担保
- 付款方式
- 交付期/服务期
- 质保期
- 违约责任
- 知识产权
- 分包/转包
- 保险要求
- 验收标准

## 注意事项

1. **逐条响应**：每一条商务条款都必须有对应的响应行
2. **避免负偏离**：负偏离可能导致废标，务必在投标前确认能否满足
3. **统一措辞**：投标函、开标一览表、偏离表中的商务承诺必须完全一致
4. **页码导航**：如招标文件要求标注响应页码，确保页码准确
