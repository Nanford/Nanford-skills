# 投标函模板

> **使用说明**: 本模板仅供参考格式框架。实际使用时，**必须以招标文件第六章提供的投标函模板为准**，只替换标注的变量部分。

---

## 标准格式

```
                          投 标 函

致：[招标人名称]：

    1. 我方已仔细研究了[项目名称]招标文件（招标编号：[招标编号]）的全部内容，
包括所有澄清说明文件。我们接受招标文件中对投标人的所有约束条件。我方愿意以所附
投标报价表中的投标报价（总价/单价），严格按照招标文件提供和交付货物及服务。

    2. 我方承诺在招标文件规定的投标有效期[XX]天内不修改、不撤销投标文件。

    3. 如我方中标：
    （1）我方承诺在收到中标通知书后，按照招标文件要求在规定的期限内与贵方签订
合同、廉洁协议及保密协议（如有需要）。
    （2）随同本投标函递交的投标报价一览表属于合同文件的组成部分。
    （3）我方承诺按照招标文件规定向贵方递交履约保证金/履约担保。
    （4）我方承诺在合同约定的期限内按合同约定完成并移交全部合同项目。

    4. 我方同意按照招标文件要求提供与我方投标有关的一切数据或资料，完全理解
贵方不一定接受最低价的投标或收到的任何投标。

    5. 我方承诺在相关案件查办时，履行配合提供证据、作证的义务。

    6. 我方承诺以[□银行转账 □银行保函]的形式在招标文件约定的时间内足额交纳
履约保证金。

    投标人名称（盖章）：___________________

    法定代表人或授权代表（签章）：___________________

    日期：______年______月______日
```

## 关键检查项

- [ ] 投标有效期天数 ≥ 招标文件要求（通常90天）
- [ ] 项目名称、招标编号与招标文件一致
- [ ] 使用招标文件原文措辞，不自行修改
- [ ] 有法人代表或授权代表签字处
- [ ] 有单位公章处
- [ ] 日期在投标截止日期之前
