# 工程总承包 / 施工类写作骨架（P3-4，`construction_epc`）

> 使用阶段：阶段2定类型 → 阶段5技术大纲与正文。
> 配套：`award-separation-defense.md`（工程类常见评定分离）、`templates/联合体协议与分工表.md`。
> **不要用 IT 服务标的骨架写工程标**：评委是工程口的，看的是工期、质量、安全、造价控制，不是"数字化赋能"。

## 一、识别信号

招标文件出现：设计施工总承包 / EPC / 工程总承包、施工组织设计、工程量清单、建造师、建筑施工企业安全生产许可证、安全文明施工、竣工验收、监理、农民工工资保障、限额设计、发包人要求。

文件结构也不同：常见"第五章 **发包人要求**"（相当于采购需求）、"第六章 发包人提供的资料"。

## 二、与既有五类的关系

`construction_epc` 是第六类主类型。复合情形：
- 装修/机电改造带弱电智能化 → 主类型 `construction_epc`，技术方案里嵌 IT 子章
- 设备采购为主、少量安装 → 仍归 `hardware_supply`
- 厂区软硬改造（WMS/WCS/PLC）→ 仍归 `hybrid_retrofit`

判定口径：**是否需要施工资质与建造师**。需要 → `construction_epc`。

## 三、资格材料清单（工程类专属，与 IT 标差异最大）

| # | 材料 | 要点 |
|---|---|---|
| 1 | 企业资质证书 | 施工资质 + 设计资质（EPC 两者都要）；**同一专业组成联合体的，按资质等级较低者确定** |
| 2 | **建筑施工企业安全生产许可证** | 联合体中**承担施工任务的各方**都要提供 |
| 3 | 项目总负责人**建造师注册证书** | 有效期内；以投标登记时选取的人为准 |
| 4 | 项目总负责人**安全生产考核合格证（B类）** | 与建造师证配对，缺一不可 |
| 5 | 设计负责人**注册建筑师注册证书** | 联合体中承担设计任务的成员单位提供 |
| 6 | 专业负责人注册证书 | 给排水/电气/暖通空调专业负责人须符合注册执业规定 |
| 7 | 企业营业执照 | 联合体各方**分别提供** |
| 8 | 联合体协议书 | 各方**分别签字盖章**（其他资料可由主办方统一签章） |

> 🚩 与 IT 标最大的不同：**人证绑定**。建造师、安全B证、注册建筑师都是绑到具体自然人的，且"以投标登记时选取的人为准"——报名时选错人，后面改不了。阶段2 就要确认人选。

## 四、联合体（工程类常态，与烟草标相反）

烟草类项目几乎都拒绝联合体；工程 EPC **接受甚至鼓励**（设计方 + 施工方）。

关键规则（原文摘要）：

| 规则 | 内容 |
|---|---|
| 协议书 | 按招标文件格式签订，明确**主办方**和各方权利义务 |
| 资质就低 | 由同一专业的单位组成的联合体，按**资质等级较低**的单位确定资质等级 |
| 排他 | 联合体各方**不得再以自己名义单独或参加其他联合体**在本项目投标 |
| 签章分工 | 《联合体协议书》须各方**分别**签章；其他资料可由**主办方**统一签章；法定代表人证明书及授权委托书由**主办方**出具 |
| 投标人名称写法 | 首页及落款的"投标人/投标单位/声明企业"须填**联合体各方全称**，格式示例：`(主)单位全称(成)单位全称` |
| 关联限制豁免 | 单位负责人为同一人或存在控股、管理关系的不同单位不得同时投标，但**联合体内各成员之间不受此限** |
| 信用查询 | 政采项目对**所有联合体成员**逐一查询；任一成员有不良记录视同联合体有 |
| 价格扣除 | 大中型与小微组成联合体、小微份额≥30% 可享 P2 扣除；但各方间有直接控股/管理关系的**不享受** |

落地表：`templates/联合体协议与分工表.md`。

## 五、技术方案主骨架（按此顺序，对齐工程口评委）

```
一、项目理解与总体实施思路
    工程概况、建设规模、场地条件、周边环境、重难点分析
二、设计方案（EPC 项目单独成册，常需单独密封/单独光盘）
    设计依据与标准、平面布局、机电系统、材料选型、效果表达
    限额设计控制措施
三、设计与施工融合方案  ← EPC 评定分离的「方案因素」核心
    融合目标、融合管理体系、融合措施、设计施工界面划分
    设计变更控制、可施工性审查、设计交底与图纸会审
四、施工组织设计
    施工总平面布置、临设布置、施工部署、主要分部分项施工方案
    施工机械与周转材料、劳动力组织、季节性施工措施
五、工期与进度计划
    总工期承诺、网络计划、关键线路、里程碑、赶工预案
六、质量管理
    质量目标与创优承诺、质量保证体系、材料进场检验
    隐蔽工程验收、实测实量、样板引路、质量通病防治
七、安全文明施工与环境保护  ← 工程标必含，权重高
    安全管理体系与责任制、危大工程专项方案、安全教育与交底
    临边洞口/用电/机械/消防、文明施工与扬尘噪声控制
    建筑垃圾处置、应急预案与演练
八、交通疏解与周边协调（市政/公共区域项目必含）
    交通疏解方案（常需招标人或设计咨询单位审核通过后方可实施）
    扰民控制、与既有运营的衔接
九、项目管理与组织保障
    组织架构、岗位职责、管理制度、沟通协调、信息化管理
    分包管理（非主体非关键性工程分包须招标人审核批准）
十、造价与变更控制
    限额设计、工程量控制、变更签证管理、结算配合
十一、竣工验收与保修服务
    验收组织与资料、竣工图、移交、保修期与响应机制
十二、履约保障与风险应对
    履约担保、农民工工资保障、风险识别与应对
```

## 六、工程类专属承诺（必须出现，缺了显得不专业）

| 项 | 写法要点 |
|---|---|
| 工期承诺 | 具体日历天，含开工条件与顺延情形 |
| 质量目标 | 一次验收合格 / 具体创优目标 |
| 安全目标 | 杜绝重大事故的量化指标（如死亡事故为零、重伤率控制值） |
| 文明施工 | 达标工地承诺、扬尘噪声控制指标 |
| 农民工工资 | 专户、实名制、按月足额支付承诺 |
| 履约担保 | 按招标文件格式与时限出具（**未按要求提交可被解除中标通知书**） |
| 临设与交通疏解 | 承诺方案经招标人/设计咨询单位审核通过后实施；**超出审核方案造价的按审核方案结算**（成本风险，须提示用户） |

## 七、常见坑

1. **临设与交通疏解的造价风险**：实际方案造价超出审核方案的，按审核方案结算——差额自己承担。报价时必须按审核口径测算。
2. **资质有效期复核**：定标结束后招标人会复核中标人资质证书有效期，若未在规定天数内提供延续核准材料，**否决中标资格**。阶段2 就要核对资质到期日。
3. **设计成果补偿**：部分 EPC 项目对未中标人给予设计成果补偿，但需满足特定条件——影响投入决策，须告知用户。
4. **分包限制**：仅非主体、非关键性工程可分包，且须招标人审核批准；分包内容/金额/资质有限制性条件。
5. **重新评标时的信息基准**：评标信息（含业绩、奖项）以**投标截止时**的信息为准，事后取得的不算。
