# 硬件采购安装类样本骨架（P1/P2 · hardware_supply）

> 提炼自设备购置、工业相机、安装调试类招标特征：**参数表、品牌/型号、到货安装、验收、质保**。  
> 使用阶段：`project_type=hardware_supply` 时阶段5 必读。  
> 忌写成空泛「信息化方案」；**参数响应与安装调试才是得分正文**。

## 一、成品技术部分推荐总结构

```
二、技术文件
├── 技术响应偏离表（逐条参数/标准，★完全满足，写清品牌型号）
├── （一）供货范围与配置说明
│   ├── 配置清单（名称/型号/数量/产地/制造商）
│   └── 与招标需求逐条对照
├── （二）技术性能与参数详细描述
│   ├── 关键指标解释与证明材料指向
│   └── 兼容性/接口/环境条件
├── （三）供货、运输与到货验收
├── （四）安装调试方案
│   ├── 进场条件与工期
│   ├── 安装步骤与测试项
│   └── 安全措施（简版可引用 safety-env）
├── （五）项目管理与进度
├── （六）培训
├── （七）质保与售后服务（响应时限量化）
└── （八）服务承诺
```

## 二、偏离表写法要点

| 列 | 要求 |
|---|---|
| 招标要求 | 原文参数 |
| 投标响应 | **具体数值/型号**，禁止只写「满足」 |
| 偏离 | 无偏离/正偏离；不允许负偏离时禁止写负 |
| 证明 | 彩页、检测报告、官网截图路径 |

## 三、安装调试最低内容

1. 进场人员与机具  
2. 安装步骤（可执行）  
3. 通电/联调/标定测试项  
4. 验收标准与记录表  
5. 安全与成品保护  

## 四、常见废标/失分

- 参数负偏离  
- 交货期短于要求  
- 品牌/产地未响应  
- 只有报价无技术方案  
- 质保响应时限与招标 SLA 不一致  

## 五、篇幅建议

- 参数与配置说明写实即可，**不必硬凑 30 页空话**
- 安装调试 + 售后应有完整段落与量化时限
