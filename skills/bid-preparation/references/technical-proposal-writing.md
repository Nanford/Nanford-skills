# 技术方案写作模式（中标样本技术部分提炼）

> 来源：湖北中烟2026-2027年应用系统服务库中标投标文件技术部分（第403-486页，共83页）逐节分析。
> 使用阶段：阶段5编制技术文件。写方案前先读本文件，按这里的骨架和文风写，不要自创结构。

## 一、总体结构（技术文件三大块）

```
二、技术文件
├── 技术响应偏离表（★条款逐条，无空项）
├── （一）技术性能、参数的详细描述        ← 约4页
│   ├── 1. 公司简介（履约能力证明）
│   │   ├── 1.1 公司简介（成立背景、主营产品、服务理念）
│   │   ├── 1.2 建设优势（面向本项目业务领域的能力论述）
│   │   ├── 1.3 技术能力优势（认证体系、方法论、开发平台工具链）
│   │   └── 1.4 项目运维优势（售后团队、响应体系、服务内容全景）
│   └── 2. 详细说明技术性能、参数
│       ├── 2.1 对招标人系统现状的技术理解（用招标文件里的规模数字说话）
│       └── 2.2 技术架构适配能力（逐维度：云环境/微服务/传统架构/集成平台/信创/数据标准）
└── （二）服务方案                        ← 每个方案30-40页
    ├── 1. XX服务方案（按评分表"编列内容"分块）
    └── 2. YY服务方案
```

## 二、单个服务方案的十节骨架（样本验证的得分结构）

以服务型运维方案为例（样本41页），每个方案按此骨架展开：

| 节 | 内容 | 得分作用 |
|---|---|---|
| x.1 招标需求响应总述 | 逐条引用招标需求原文→紧跟"我方已充分理解……我方方案在「X节」覆盖……" | 让专家30秒确认全覆盖，无负偏离 |
| x.2 项目理解与总体思路 | 招标人现状调研 + N大挑战识别 + 应对理念 + 技术环境适配维度 | 证明"懂客户"，区分度最高的一节 |
| x.3~x.7 核心方案主体 | 严格按评分标准"编列内容"列出的领域逐块展开（如：交维与下线/维护与故障处理/监控与巡检/安全管理/优化改进） | 评分主体，每块对应评分子项 |
| x.8 人员管理及保障 | 组织架构（三级）、人员配置（数字）、考核、稳定性承诺 | 对应团队类评分项 |
| x.9 评估与改进 | 质量评估体系、KPI指标、月报/季评/年度总结、PDCA | 对应服务管理类评分项 |
| x.10 服务承诺 | 信函式，致招标人+代理机构抬头，8-9条量化承诺，落款盖章 | 收尾定调，量化指标可被引用打分 |

开发建设类方案的主体节按生命周期展开：需求调研与分析 → 系统设计（按4A：业务/数据/应用/技术/安全架构逐一设计）→ 开发测试 → 上线验收 → 售后质保 → 项目管理配套（组织/沟通/风险/变更/进度）→ 服务承诺。

## 三、文风规则（"像标书"和"像清单"的分界线）

1. **成段论述**：每个小节正文是完整段落，模式为"定位/原因 → 机制/流程 → 量化承诺"。
   - ❌ 碎片清单：`2.1.1 交接启动：中选通知书发出后，我方立即启动交接准备。`
   - ✅ 成段论述：`运维服务交接是将系统从建设方顺利过渡到我方运维团队的关键环节。依据招标文件中"中标人可提前开展运维服务交接工作"的要求，我方将在中选通知书发出后3个工作日内成立交接工作组，由项目经理担任组长……交接计划经招标人审批后作为交接工作的执行基线。`
2. **每个大节先写引言段**：一段话总述本节定位与价值，再进小节。
3. **段内列举**用"（1）（2）（3）"或"第一/第二/第三"或"挑战一/挑战二"，每项都是完整多句论述，不是短语。
4. **量化到数字**：没有数字的承诺不得分。时限（3个工作日/30分钟内回滚）、指标（可用率≥99.9%、P50/P95/P99）、阈值（CPU≥85%告警）、人数（驻场≥12人）、周期（每季度权限审计、每月备份演练）、留存（日志在线30天/归档2年）。
5. **呼应招标原文**：关键参数、系统规模、专有名词与招标文件完全一致（如"140套自建系统、40套统建系统、4000余个接口"），并在响应总述中显式引用。
6. **表格只用于天然表格化内容**：SLA分级表（等级/定义/响应时限/恢复目标/通知方式/升级时限）、KPI指标、评分权重、风险矩阵。正文不得表格化。
7. **标题层级**：方案主节用 1. / 1.1（Word 标题3/4级），更深的 1.1.1 和 1.1.1.1 用整行加粗段落（`**1.1.1 标题**`），保持目录清爽。
8. **成品语言**：`我方承诺…`、`我方方案「X节」明确…`、`确保…同时不越权承诺`；禁止出现写作过程语言。

## 四、服务承诺节的固定写法

```
致：<招标人全称>、<代理机构全称>

我司在参与贵司<项目名称>（招标编号：XXX）项目投标活动中，
我司对<方案对应服务>做出如下郑重承诺：

1. <团队规模承诺，具体人数与覆盖地域>
2. <支持渠道承诺，7×24小时+渠道列举，与招标文件列举方式一致>
3. <SLA承诺，逐级列出响应/恢复时限，与方案正文SLA表一致>
4. <制度遵从承诺，点名招标人管理制度名称>
5. <安全合规承诺，点名法律法规和招标人安全责任书>
6. <免费服务额度承诺，公式与招标文件完全一致>
7. <人员稳定承诺，项目经理服务时长+更换通知期>
8. <知识产权归属承诺>
9. <应急保障承诺>

投标人名称：XXX（盖单位公章）
日期：XXXX年XX月XX日
```

## 五、篇幅基准与自检

- 单个服务方案成稿 **30页以上**（样本：41页/38页）；响应总述2-5页、项目理解2-3页、每个核心领域节3-6页
- 自检清单：
  - [ ] 评分标准"编列内容"每一块都有对应章节
  - [ ] 每节开头有引言段
  - [ ] 无一行一条的碎片清单段
  - [ ] 每节至少一组量化承诺数字
  - [ ] 招标文件的规模数字/专有名词在方案中出现且一致
  - [ ] 方案结尾有信函式服务承诺并落款
