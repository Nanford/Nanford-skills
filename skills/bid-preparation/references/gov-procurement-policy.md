# 政府采购政策包（P3-2）

> 使用阶段：`procurement_system = gov` 时**必读**；阶段2建表、阶段3备料、阶段4填函、阶段7核验。
> 落盘：`analysis/gov-policy-checklist.md`（模板 `templates/政府采购政策核对表.md`）。
> **这是政府采购项目里性价比最高的分**：一张《中小企业声明函》可能相当于报价打八折，成本几乎为零。
> 所有比例、清单、平台以**招标（磋商）文件原文和最新品目清单为准**，本文给的是通用值与核对方法。

## 一、价格扣除（最重要，直接改写报价得分）

### 1.1 政策依据

- 《政府采购促进中小企业发展管理办法》（财库〔2020〕46号）
- 《关于进一步加大政府采购支持中小企业力度的通知》（财库〔2022〕19号）

### 1.2 扣除比例（通用值，**必须以招标文件原文为准**）

| 情形 | 代号 | 货物 / 服务 | 工程 | 证明材料 |
|---|---|---|---|---|
| 供应商为小型/微型企业，货物全部由小微制造、服务全部由小微承接、工程施工单位全部为小微 | **P1** | 10%（部分地区/项目提高至 **20%**） | 5% | 《中小企业声明函》 |
| 大中型企业与小微组成联合体，或向小微分包，且**小微合同份额 ≥30%** | **P2** | 4% | 2% | 联合协议/分包意向协议 + 声明函 |
| 监狱企业 | 同 P1 | 视同小型、微型企业 | 同左 | 省级以上监狱管理局/戒毒管理局出具的证明文件 |
| 残疾人福利性单位 | 同 P1 | 视同小型、微型企业 | 同左 | 《残疾人福利性单位声明函》 |
| 节能产品 / 环境标志产品（优先采购类） | — | 各 1%（见本文第二节） | 同左 | 认证证书 + cx.cnca.cn 截图 |

计算公式：

```
评审价（评标价） = 响应报价 × (1 - 扣除比例)
报价得分 = (基准价 ÷ 评审价) × 价格分值
基准价 = 满足文件要求且评审价最低者的评审价
```

### 1.3 五条必须记住的细则

1. **企业属性重复不叠加**：既是小微又是监狱企业/残疾人福利性单位的，只享受一次扣除，不重复计算。
2. **中小企业政策与本国产品优惠可叠加**：两项价格评审扣除**均在原始报价基础上计算**，用扣除后价格参与评审（四川磋商文件明确）。
3. **已作为评审因素评分的不再价格扣除**：节能/环标若已在技术分里给了分，就不再给价格扣除，别重复指望。
4. **不交声明函 = 不享受**：招标文件原文——"参加本项目投标的小型和微型企业应当提供《中小企业声明函》，**否则不得享受相关中小企业扶持政策**"。这是纯粹的手续分，漏交等于自己放弃。
5. **联合体/分包内部有控股管理关系的不享受**：小微与联合体内其他企业、分包企业之间存在直接控股、管理关系的，不享受价格扣除优惠。

### 1.4 工程类的特殊算法（易错）

适用招标投标法的**政府采购工程建设项目**，采用综合评估法但**未采用低价优先法**计算价格分的：
不是扣价格，而是**在原报价评分基础上按 5%（P1）/ 2%（P2）增加其价格得分**。
→ 遇工程类政采项目，先看价格分算法是不是低价优先法，再决定套哪种算式。

### 1.5 声明函的填写红线

- **必须用招标文件给的官方格式**，不得自拟版式（P0#3 格式克隆已覆盖）
- 企业划型依据《中小企业划型标准规定》（工信部联企业〔2011〕300号），按**所属行业**的从业人员、营业收入、资产总额判定，不能凭感觉填
- 与大企业负责人为同一人，或与大企业存在直接控股、管理关系的，**不算中小企业**
- 新成立企业无上一年度数据的，凭声明函认可其为中小企业
- **成交后声明函会随成交结果公开**；不实声明属提供虚假材料谋取成交，后果是列入不良行为记录名单
- 声明函存在明显笔误或含义不明确的，评审时会要求澄清补正——填表时务必字段完整、口径一致

> 🚩 **阶段2 必做**：把本项目的实际扣除比例、我方企业属性、能否享受、需要哪份证明，逐行填入 `gov-policy-checklist.md` 第一节，并**测算扣除前后的评审价**。这直接决定报价策略。

## 二、强制采购 / 优先采购节能环标产品（漏了直接无效响应）

| 类别 | 后果 | 材料要求 |
|---|---|---|
| **强制采购**节能产品（品目清单内标注强制的） | **不提供 = 作无效响应处理**（废标级） | 国家确定的认证机构出具的、**有效期内**的节能产品认证证书原件扫描件，或"全国认证认可信息公共服务平台"（http://cx.cnca.cn）认证信息截图 |
| **优先采购**节能产品 | 享受优先采购政策 / 1% 价格扣除 | 同上 |
| **优先采购**环境标志产品 | 享受优先采购政策 / 1% 价格扣除 | 环境标志产品认证证书，同上 |

清单依据：财政部、发展改革委、生态环境部等部门发布的**最新**《节能产品政府采购品目清单》《环境标志产品政府采购品目清单》。

**执行要点**：
1. 阶段2 先在采购需求前附表找"是否涉及强制采购节能产品 / 优先采购节能产品 / 优先采购环境标志产品"三行，逐行记下"涉及/不涉及"
2. 涉及强制采购的，响应文件里**必须明确列明具体产品名称**，再附证书——只附证书不写产品名同样有风险
3. 证书与截图**配对提供**（与既有"证书+官方平台截图"规则一致）
4. 顺带核对：列入《实施强制性产品认证的产品目录》的产品，验收时须出具 CCC 认证证书；涉及软件的须承诺采购使用正版软件、办公计算机预装正版操作系统

## 三、信用记录查询（资格性检查，拒绝即出局）

依据《关于在政府采购活动中查询及使用信用记录有关问题的通知》（财库〔2016〕125号）。

| 平台 | 网址 | 查什么 |
|---|---|---|
| 信用中国 | www.creditchina.gov.cn | 重大税收违法失信主体、严重失信主体 |
| 中国政府采购网 | www.ccgp.gov.cn | **政府采购严重违法失信行为记录名单** |
| 中国执行信息公开网 | http://zxgk.court.gov.cn/shixin/ | 失信被执行人 |

**要点**：
- 查询时点为**提交响应文件截止时间前**，须保存网页截图
- 被列入上述任一名单的**拒绝参与**
- **组成联合体的，所有成员逐一查询**；任一成员有不良记录，视同联合体有不良记录
- 查询主体可能是采购人/代理机构，也可能要求供应商自查并附截图——**以招标文件分工为准**，要求供应商提供的必须自己截图入册

> 注意：这三个平台与企业采购（如烟草）常用的"五平台"口径**不同**。政采项目按本表，别照搬烟草清单。

## 四、资格要求三段式（政采特有的结构）

政府采购文件的资格条款通常分三段，逐段核对，缺一不可：

| 段 | 名称 | 内容 | 核对方式 |
|---|---|---|---|
| 一 | **一般资格要求** | 《政府采购法》第二十二条：独立承担民事责任能力、良好商业信誉和健全财务会计制度、履行合同所必需的设备和专业技术能力、依法缴纳税收和社保、参加采购活动前三年内经营活动中无重大违法记录 | 逐条附证明，通常有官方承诺函格式 |
| 二 | **落实政府采购政策需满足的资格要求** | 填"无"或填"本项目专门面向中小企业采购/面向小微企业预留份额" | 若为**专门面向中小企业**，则非中小企业**根本没有投标资格**——这是资格门槛，不是加分项，必须最先确认 |
| 三 | **本项目的特定资格要求** | 行业许可、业绩、人员、认证等项目定制条件 | 逐条对应证明材料，进资格审查导航表 |

> 🚩 第二段是最容易被忽略又最致命的：如果项目"专门面向中小企业"而我方是大中型企业，投了也是无效响应，应在阶段2 立刻停下来告知用户。

## 五、地方性信用评价分（可能直接进商务分）

部分地区把地方公共资源交易平台的信用评价分**折算进商务分**。例如广州：

> 综合信用评价得分 = 投标人的广州公共资源交易信用评价（政府采购供应商信用评价分）× 5%
> 以开标当天平台公布的分值为准；未能查询到的按当天信用评价基准分计算；联合体以牵头方分值计算。

**执行要点**：
- 阶段2 识别是否存在此类条款，若有，**提前登录当地平台查自家分值**并想办法提分（补业绩、补良好行为记录），这是开标当天就锁定的分，事后无法补救
- 记入 `scoring-strategy.md` 的机械得分项，标注"需提前N天处理"

## 六、其他政采常见条款

| 条款 | 要点 |
|---|---|
| 进口产品 | 未标明涉及进口产品的，**不得提供进口产品响应**；标明涉及的，国产满足需求也可用国产 |
| 相同品牌 | 单一产品项目提供相同品牌、非单一产品项目提供相同品牌**核心产品**的不同供应商，**按一家计算**；得分最高者获推荐资格 |
| 政府采购合同 | 严禁转包，违规分包属违法情形；合同自双方签章之日起生效 |
| 履约验收 | 政采文件常列明验收组织方式、是否邀请其他供应商/专家/服务对象/第三方检测机构、技术与商务验收内容——**写实施方案时须与之对齐** |
| 质疑投诉 | 供应商可依法质疑、投诉；须留意质疑时限与提交资料要求，作为落标后的救济手段（不进标书正文，记入项目档案） |
| 供应商信用融资 | 部分省份提供"政采贷"，凭成交通知书向银行融资——资金紧张时的备选，不影响标书编制 |
