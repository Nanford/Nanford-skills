# references 目录说明

本目录存放 `bid-preparation` Skill 在不同阶段按需读取的参考卡片。

| 文件 | 使用阶段 | 内容边界 |
|---|---|---|
| `stage-0-init.md` … `stage-7-review.md` | 对应阶段 | 各阶段执行细则（目标/双平台命令/硬性要求/完成标志/状态更新），进入该阶段前必读——SKILL.md 只保留路由与红线 |
| `tobacco-industry-notes.md` | 解标分析、资料匹配 | 行业提示（烟草体系样例）；行业惯例一律以招标文件说明为准，非烟草体系不得照搬 |
| `bid-structure-analysis.md` | 解标分析 | 招标文件结构、字段提取和输出要求 |
| `mandatory-clause-guide.md` | 强制条款识别 | `★`、否决、无效投标和承诺类条款处理 |
| `scoring-patterns.md` | 评分矩阵与技术组织 | 技术、商务、价格评分映射方式 |
| `document-checklist.md` | 成稿与合规审查 | 商务、资格、技术文件清单和最终检查 |
| `response-file-format.md` | 商务/技术编制、DOCX组装 | 成品投标文件格式规范（基于真实中标格式样本）：组装顺序、三张导航表、五件套/三件套、分页与版式规则、组装标记 |
| `technical-proposal-writing.md` | 技术文件编制 | 技术方案写作模式（中标样本技术部分83页逐节提炼）：十节骨架、成段论述文风规则、量化承诺、服务承诺固定写法、篇幅基准 |
| `industry-common-terms.md` | 正文写作 | 可直接用于标书的机制化表达 |

参考文件只提供判断框架，不替代招标文件原文。招标文件、澄清、补遗和官方格式始终优先。
