# references 目录说明

本目录存放 `bid-preparation` Skill 在不同阶段按需读取的参考卡片。

| 文件 | 使用阶段 | 内容边界 |
|---|---|---|
| `stage-0-init.md` … `stage-7-review.md` | 对应阶段 | 各阶段执行细则；P0 硬门禁 + **P3 采购路由** + **P1 类型路由** |
| `procurement-mode-routing.md` | 阶段0/2/4/5/6 | **P3（先执行）** 采购体系 gov/enterprise、五种采购方式、术语映射表、磋商两阶段报价 |
| `gov-procurement-policy.md` | 阶段2/3/4/7 | **P3** 政府采购政策包：价格扣除测算、强制/优先采购节能环标、政采信用查询、资格三段式、地方信用评价分 |
| `award-separation-defense.md` | 阶段2/4/5/**6**/7 | **P3** 评定分离：投标文件双分册、定标因素表、答辩预案、票决机制 |
| `sample-construction-epc.md` | 阶段2/5 | **P3** 工程总承包写作骨架、人证绑定资格材料、联合体规则 |
| `project-type-routing.md` | 阶段0/2/4/5/6 | **P1（后执行）** 六类项目类型、递交方式、专章裁剪 |
| `sample-hybrid-retrofit.md` | 阶段5 | 软硬改造类结构与深度骨架 |
| `sample-hardware-supply.md` | 阶段5 | 硬件采购安装类结构与深度骨架 |
| `tobacco-industry-notes.md` | 解标分析、资料匹配 | 行业提示（烟草体系样例）；行业惯例一律以招标文件说明为准，非烟草体系不得照搬 |
| `bid-structure-analysis.md` | 解标分析 | 招标文件结构、字段提取和输出要求 |
| `mandatory-clause-guide.md` | 强制条款识别 | `★`、否决、无效投标和承诺类条款处理 |
| `scoring-patterns.md` | 评分矩阵与技术组织 | 技术、商务、价格评分映射方式 |
| `document-checklist.md` | 成稿与合规审查 | 商务、资格、技术文件清单和最终检查 |
| `response-file-format.md` | 商务/技术编制、DOCX组装 | 成品投标文件格式规范（基于真实中标格式样本）：组装顺序、三张导航表、五件套/三件套、分页与版式规则、组装标记 |
| `technical-proposal-writing.md` | 技术文件编制 | 技术方案写作模式：十节骨架、正文直接写需求内容且不写采购文件来源编号、**项目管理/实施方案必含**、成段论述、量化承诺、防 Markdown 泄漏、对照用户响应样本 |
| `industry-common-terms.md` | 正文写作 | 可直接用于标书的机制化表达 |

参考文件只提供判断框架，不替代招标文件原文。招标文件、澄清、补遗和官方格式始终优先。
