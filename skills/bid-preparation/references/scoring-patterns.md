# 评标评分模式参考

基于14份招标文件分析得出的评分模式。

## 评分三大维度

几乎所有综合评估法都包含三个维度：

| 维度 | 典型权重范围 | 说明 |
|------|-------------|------|
| **价格部分** | 30-50分 | 基准价公式计算，偏离扣分 |
| **技术部分** | 25-45分 | 技术方案+实施+团队+售后 |
| **商务部分** | 15-35分 | 认证+业绩+团队资质+财务 |

## 不同类型项目权重分布

| 项目类型 | 价格 | 技术 | 商务 | 代表项目 |
|----------|------|------|------|----------|
| IT系统建设 | 30-36 | 30-45 | 25-34 | 卷包数采、物流可视化 |
| 维保服务 | 50 | 43 | 7 | 贵阳卷烟厂维保 |
| 硬件采购安装 | 50 | 35 | 15 | 乐道工业相机 |
| 数字孪生 | 30 | 35-40 | 30-35 | 宝鸡高架库 |
| 创新项目（小额） | 资格+符合 | 定性 | 资格+符合 | 恩施车辆可视化 |

## 价格评分公式（最常见）

### 模式A：均价基准法
```
基准价 = 所有有效投标报价的平均值
        （如≥6家则去掉一个最高和一个最低）

价格得分 = 满分 × (1 - |报价 - 基准价| / 基准价 × Q)

其中：报价 > 基准价时 Q = 0.3~0.6（扣分多）
      报价 < 基准价时 Q = 0.2~0.3（扣分少）
```

### 模式B：最低价基准法
```
基准价 = 有效报价中的最低价

价格得分 = 基准价 / 投标报价 × 满分
```

### 模式C：前N名基准法
```
基准价 = 技术商务得分前N名投标人的报价均值

（湖北中烟系常见模式）
```

### 报价策略提示
- 低于最高限价60-70%可能触发低价质疑
- 低于50%基本会被要求提供成本说明
- 接近均价最安全，但需结合企业情况

## 技术评分常见子项

| 常见子项 | 典型分值 | 得分策略 |
|----------|----------|----------|
| 技术参数响应 | 8-14 | ★全部满足，▲积极响应，一般条款不偏离 |
| 系统设计方案 | 5-10 | 分层设计：应用、技术、数据、安全、部署 |
| 项目理解 | 3-6 | 展示对用户业务的理解深度 |
| 功能需求响应 | 5-10 | 逐条对应，提供界面原型更好 |
| 系统集成方案 | 3-8 | 接口规范、数据交换方式、兼容性 |
| 项目实施管理 | 4-10 | 进度计划+质量保证+风险管理 |
| 售后服务方案 | 3-8 | 响应时间+服务团队+质保期延长 |
| 培训方案 | 2-5 | 分层培训（操作/管理/技术） |
| 信息安全方案 | 3-6 | 等保合规+数据加密+访问控制 |
| 项目团队 | 3-14 | 证书越多越好，提供社保证明 |

## 商务评分常见子项

| 常见子项 | 典型分值 | 得分策略 |
|----------|----------|----------|
| 体系认证 | 2-5 | ISO9001/14001/45001/27001/20000各1分 |
| CMMI等级 | 1-3 | CMMI3-5级各有分数 |
| ITSS认证 | 1-2 | 信息技术服务标准 |
| 纳税信用等级 | 1-2 | A级最优 |
| 类似业绩 | 6-15 | 以大金额、近年为优 |
| 项目团队资质 | 3-14 | PMP、高级工程师、信息安全等证书 |
| 质保期延长 | 1-6 | 每延长6个月额外加分 |
| 软件著作权 | 2-4 | 相关领域的软著 |
| 投标文件编制质量 | 1-2 | 目录完整、格式规范 |

## 评分优化核心策略

### 策略1：按评分表顺序写技术方案
评标专家手中有评分表，他们按表逐项打分。
技术方案的章节编号应直接对应评分表编号。

### 策略2：每个评分点独立成节
不要把多个评分点混在一个章节里。
每个评分点一个独立小节，标题清晰，让评标专家容易定位。

### 策略3：突出★和▲响应
★条款用加粗/特殊标记标注"完全满足"
▲条款注明超越标准的具体说明

### 策略4：业绩证明要完整
缺发票的业绩 = 不被认可的业绩
合同+发票+验收报告，三件齐全

### 策略5：团队配置宁可多不可少
多列几个有证书的成员不会扣分
但少了一个★要求的人员直接废标
