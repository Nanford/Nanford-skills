# 阶段4细则：编制商务文件

> **生成范围为"仅技术部分"（technical-only）时跳过本阶段，直接进入阶段5。**
> 配套阅读：`references/response-file-format.md`（商务文件十二件套 + 组合拳）、`references/industry-common-terms.md`（成品表达）。

## 目标

严格按招标文件第六章格式生成商务响应文件。**招标文件提供了格式模板的，只填空白处，不得修改模板文字。**

## 按成品组装顺序编制（十二件套）

1. **投标函** — 原文模板，只替换项目名、投标人、有效期、日期；有效期必须 ≥ 招标要求
2. **投标一览表/开标一览表** — 报价（含税/不含税）、税率、质保期、交付期；**不得超最高限价**
3. **投标分项报价表** — 逐项报价，合计与总价一致
4. **商务响应偏离表** — 逐条响应，**不允许空项**；无偏离填"无偏离"，有偏离注明正/负偏离
5. **法定代表人身份证明** — 附身份证正反面；信息与营业执照一致
6. **法人授权委托书** — 授权期限覆盖投标有效期
7. **廉洁自律承诺书等承诺书类** — **原文照抄，一字不改**
8. **投标保证金** — 三件套齐全，金额与要求一致，从基本户转出
9. **资格审查资料** — 基本情况表、营业执照、信誉声明、资格承诺书、非联合体声明、信用截图等
10. **近年财务状况** — 按要求年份的审计报告
11. **类似业绩证明** — 每项业绩五件套齐全；合同签订时间落在招标要求的时间窗口内
12. **项目管理机构及人员** — 人员资历表 + 每人三件套 + 团队成员类似业绩合同
13. **其他商务材料** — 体系认证+查询截图、纳税信用、额外加分资质、需说明的承诺书

每份文件末尾落款：`投标人：XXX（盖单位公章）` / `法定代表人或授权代表：（签章）` / 日期。

## 证明材料排版规则（与中标样本一致）

- 资料库中**已有扫描件的**（营业执照、认证证书等），用 Markdown 图片语法直接插入：`![营业执照](相对路径.png)`，组装时自动居中并按可打印区域缩放，禁止只写文件路径文字
- 资料库中**暂缺的**，写一个小节标题 + 一行留空占位：`（此处附：XXX扫描件）`，每份证明材料独立一页（占位行会渲染为五号红色斜体并进入人工核查清单）
- 证书评分项必须"证书页 + 官方平台查询截图页"配对成节（如 附1.1 证书 / 附1.2 查询截图）
- 商务文件 Markdown 首行加 `<!-- break-all-headings -->`，实现每一章节/小节/每份证明材料独立起页

## 自检

格式与第六章一致、签章位置齐全、报价数字前后一致、偏离表无空项。

## 完成标志

```powershell
python -X utf8 <scripts>\project_status.py "bid-projects\<项目>" --complete 4
```
