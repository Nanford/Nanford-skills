# 行业通用术语

## 烟草行业投标术语

### 组织与系统
| 术语 | 说明 |
|------|------|
| 中国烟草总公司 | 全国烟草行业主管单位 |
| 中烟工业有限责任公司 | 卷烟生产企业（如湖北中烟、江西中烟、厦门烟草） |
| 卷烟厂 | 具体的卷烟制造工厂 |
| 烟草行业黑名单 | 行贿行为供应商名单，进入即禁入 |
| 采购管理系统 | 烟草企业内部采购管理平台 |
| 公e采 | 厦门烟草系电子招标平台 |

## 投标通用术语

### 招标投标基本术语
| 术语 | 英文 | 说明 |
|------|------|------|
| 招标人 | Tenderee | 发布招标的单位 |
| 投标人 | Bidder | 参与投标的单位 |
| 招标代理机构 | Tendering Agent | 受招标人委托组织招标的机构 |
| 评标委员会 | Evaluation Committee | 负责评标的专家组 |
| 中标人 | Successful Bidder | 最终获得合同的投标人 |
| 综合评估法 | Comprehensive Evaluation | 考虑商务+技术+价格综合评分 |
| 经评审的最低投标价法 | Evaluated Lowest Price | 技术合格后价格最低者中标 |
| 资格后审 | Post-qualification | 评标时审查资格 |
| 资格预审 | Pre-qualification | 投标前先审查资格 |

### 投标文件术语
| 术语 | 说明 |
|------|------|
| 正本/副本 | 投标文件原件和复印件 |
| 胶装 | 不可拆卸的装订方式 |
| 偏离表 | 对招标文件条款的响应状态声明 |
| 无偏离 | 完全响应，不修改 |
| 正偏离 | 超过招标要求 |
| 负偏离 | 不满足招标要求（可能导致废标） |

### 保证金与担保
| 术语 | 说明 |
|------|------|
| 投标保证金 | 投标时缴纳，防止随意撤标 |
| 履约保证金/履约担保 | 中标后缴纳，保证合同履行 |
| 银行保函 | 银行出具的担保函 |
| 电汇 | 通过银行转账缴纳保证金 |

### 评分常用术语
| 术语 | 说明 |
|------|------|
| 基准价 | 评标中用于计算价格得分的参考价 |
| 最高投标限价 | 超过此价格即废标 |
| CMMI | 软件能力成熟度模型集成 |
| ITSS | 信息技术服务标准 |
| PMP | 项目管理专业人员认证 |
| CISP/CISSP | 信息安全相关认证 |
