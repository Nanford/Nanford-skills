# 招标文件通用结构分析

基于14份真实招标文件（烟草、物流、IT行业，2022-2025年）的深度分析。

## 标准6章结构

几乎所有正式招标文件都遵循以下结构：

| 章节 | 标题 | 主要内容 | 投标人关注点 |
|------|------|----------|-------------|
| 第一章 | 招标公告 | 项目概况、资格要求、时间节点、联系方式 | 自身是否符合资格条件 |
| 第二章 | 投标人须知 | 前附表（关键参数汇总）+ 详细投标规则 | 保证金、有效期、装订要求 |
| 第三章 | 评标办法 | 资格审查表 + 符合性审查表 + 详细评分表 | **得分点** |
| 第四章 | 采购需求/技术规范 | 技术规格、功能需求、交付要求 | ★条款、▲条款 |
| 第五章 | 合同条款/格式 | 合同模板、付款方式、违约责任 | 是否能接受 |
| 第六章 | 投标文件格式 | 商务文件+技术文件的格式模板 | **响应文件模板** |

## 章节变体

部分招标文件会合并或调整章节：

- **5章节版**：将"采购需求"和"技术规范"合并为一章
- **7章节版**：在标准6章基础上增加"合同格式"为独立章节
- **简化版**（小项目）：仅有"采购邀请与需求"+"响应文件格式"两部分
- **分卷版**（大项目）：分为第一卷（商务）、第二卷（技术）、第三卷（格式）

## 常见章节内容详解

### 第一章 招标公告
```
1. 项目概况与采购内容
   1.1 项目名称
   1.2 采购内容/采购清单
   1.3 最高投标限价
   1.4 交货期/服务期
   1.5 质保期要求
2. 投标人资格要求
   2.1 一般条件（独立法人、信用记录）
   2.2 特殊条件（行业资质、业绩要求）
3. 其他事项
4. 招标文件的获取
5. 投标文件的递交
6. 开标方式、时间、地点
7. 发布公告的媒介
8. 联系方式
```

### 第二章 投标人须知前附表
前附表是浓缩的关键参数，必须以表格形式提取：

| 常见参数 | 说明 |
|----------|------|
| 最高投标限价 | 超过即废标 |
| 投标保证金 | 金额、形式（电汇/保函）、到账时间 |
| 投标有效期 | 通常90天，投标函中必须≥此天数 |
| 投标文件份数 | 正本1+副本N+电子版 |
| 是否接受联合体 | 绝大多数烟草项目不接受 |
| 是否允许分包 | 绝大多数不允许 |
| 踏勘现场 | 是否组织 |
| 投标预备会 | 是否召开 |
| 履约担保 | 中标后提供，金额和形式 |

### 第三章 评标办法
见 `scoring-patterns.md` 详细分析。

### 第四章 采购需求/技术规范
关键技术要求：
- 系统架构要求（微服务、前后端分离等）
- 技术平台要求（操作系统、数据库、中间件）
- 功能需求清单
- 性能指标（响应时间、并发数等）
- 安全要求（等保级别、数据加密等）
- 集成接口要求
- 标记：★（强制）、▲（重要加分）、无标记（一般）

### 第五章 合同条款
关键条款：
- 付款方式和条件
- 知识产权归属（通常归招标人）
- 质保期和保修责任
- 违约责任
- 保密条款
- 廉政合同（烟草行业特有附件）

### 第六章 投标文件格式
见 `document-checklist.md` 详细清单。

## 烟草行业招标特点

1. **行贿记录严格**：中国裁判文书网+烟草行业黑名单双重排查
2. **廉政合同**：厦门烟草系招标文件中廉政合同为必备附件
3. **不接受联合体**：几乎所有烟草行业招标都不接受联合体投标
4. **业绩证明严格**：合同关键页+发票+银行收款凭证，缺一不可
5. **社保证明严格**：投标截止前连续6个月
6. **黑名单现场查询**：评标现场代理机构实时查询
