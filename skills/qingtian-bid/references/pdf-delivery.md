# 完整 PDF 导出与验收

阶段 7 的 DOCX 门禁放行后执行。`output/施工组织设计.docx` 为同版可编辑文件，`output/施工组织设计.pdf` 为完整交付 PDF。封面、目录、正文、插图和附表以当前项目锁定格式与招标文件为准。递交时按招标文件选定文件格式。

1. 在 Word/WPS 更新目录和页码、保存、关闭。按阶段 7 清理作者、单位和自定义属性，处理批注、修订、身份字段和残留。对当前 DOCX 取得已放行的门禁报告。
2. 运行导出命令。脚本用本机 Word/WPS 打开终稿副本，导出完整 PDF。新写 PDF 时保留页面内容，清理文档信息字典、XMP 元数据、文档 ID、批注及关联附件等附带信息，并核对清理前后每页正文、页数以及最终章节标题、图题和篇幅上限。页面文字、图中可见标识、页眉页脚仍按暗标规则逐页检查。
3. 打开清理后的最终 PDF，逐页核对目录页码、边框续接、图题与对应工序、无截断漏页及无可见身份信息。检查每个必需配图的实际落点；查看原图和 PDF 清晰度，避免用正文截图冒充可检索内容。检查通过后用 `--reviewed` 记录本版检查结果，再用 `--check` 核对当前文件。

```powershell
python -X utf8 "<skill目录>/scripts/export_response_pdf.py" <项目目录> [--office auto|word|wps]
python -X utf8 "<skill目录>/scripts/export_response_pdf.py" <项目目录> --reviewed
python -X utf8 "<skill目录>/scripts/export_response_pdf.py" <项目目录> --check
```

`review/pdf-delivery.json` 保存 DOCX 和 PDF 的哈希、页数、导出应用与检查时间。修改正文、图片或 PDF 后，重新核对并导出。不交付未经检查的导出稿或身份清理前的文件。无法渲染或导出时，保留已有 DOCX 并明确 PDF 尚未完成。

身份清理针对签章前文件的作者、创建者、生成应用、修改人、元数据及附带对象。输入或同名目标已有数字签名、签名域或加密时，使用签章前的终稿重新导出。平台要求的电子签章、加密和上传在后续制作环节按招标文件执行。
