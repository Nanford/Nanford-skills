# references 目录说明

本目录存放 `qingtian-bid` Skill 在不同阶段按需读取的参考卡片。前三份文件互相引用编号：红线 R、青天逻辑 Q、门禁 B 和 W；阶段细则按阶段编号命名，引用这些编号。

| 文件 | 使用阶段 | 内容边界 |
|---|---|---|
| `visual-layout.md` | 阶段 0、4～7 | 默认框式版面与无框例外、五种内容单元、图文评分落点、连续分隔线框/组图/表格语法与最终渲染检查；不定义官方评分权重 |
| `pdf-delivery.md` | 阶段 7～8 | 通过 DOCX 门禁后导出整份 PDF，清理文件身份属性，逐页验收并核对最终版本 |
| `installation.md` | 安装、检查与更新 | GitHub CLI 单独安装、来源记录、首次使用提醒与手动更新 |
| `image-generation.md` | 阶段 4～6 | 当前 Agent 图片技能/工具发现、工艺生成与技术图分流、图片溯源、哈希检查和能力缺失处理 |
| `redlines.md` | 开工前；阶段 2、4、5、7、8 | 第一层投标基础红线 R1～R28：红线原文、在施组里的落地方式、检查方式；P0 对应；商务侧红线及其合肥形态和触发条件；默认写法怎样让位；维护规则 |

| `stage-0-init.md` | 阶段 0 | 安装和环境自检、开工四问的问法、成品格式四种定法与命令对应、`prepare_project.py` 的产出、样张确认（只认用户明确同意）、格式锁、确认后改格式、本阶段硬停止 |
