# 施工组织设计目录与编制深度

适用阶段：4 编排目录和响应矩阵，5 分章编制，7 成品技术复核。章节顺序和一级标题服从本项目招标文件。招标未列评审内容时，沿用阶段 4 的章节确认规则。

## 一、目录层级

- 封面、目录和技术正文分别起页，按招标文件及已确认格式取舍。原生目录默认列评审项，招标要求时按指定层级展开。目录文字、顺序与最终页码逐一核对。封面字段、暗标和分页标记见 `stage-6-assembly.md`。
- 一级标题一一对应评审项，保留原文字序和章节顺序。二级标题按项目实际的专业分部、系统、分区和专项主题拆分。三级标题用于有独立做法、风险、检验或交接条件的分项。
- 同级编号使用同一体系。分章稿的二、三级标题应与图文计划的落点一致。一个控制点只在主责章节写全，其他章节通过章节、图号或表号引用。方法章写施工过程，质量章写如何判定合格，安全章写作业许可与停复工条件，重难点章写跨工序或跨使用方协调。

下表用于常见评审项的二、三级目录策划。现场不涉及的分项按范围省去。评审项合并、名称不同或另有指定内容时，按实际评审项映射。

| 评审项 | 二、三级标题按项目选取 | 核对交付内容 |
|---|---|---|
| 工程概况 | 编制依据与实质性条款响应（一是范围与界面、二是工期与质量、三是危大工程、四是材料与设备、五是文明施工与环保，或列“实质性条款与目标响应表”）；原状、周边与施工条件；主要子项与工程量界面；施工分区、阶段与移交 | 现状和拟定部署分别有依据；实质性要求逐条有响应值和对应章节；标清新建、拆除、保留、移位、恢复以及与其他单位的接口 |
| 主要施工方法 | 按招标分部展开；既有改造依次核对保护性拆除、结构加固、屋面及有水部位防水、立面门窗、装修、电气、给排水、消防、暖通、智能化、室外配套与联调 | 不同部位的构造、施工窗口、接口或验收要求有实质差异时拆为独立小节，结构加固按实际加固类型拆分，装修区分基层、地面、墙面、吊顶和收口 |
| 拟投入的主要物资计划 | 物资用量与批次；深化、封样和长周期采购；报验、仓储与领用 | 关联工程量、规格、首批及后续到场节点、需用部位、复验或仓储条件 |
| 拟投入的主要施工机械、设备计划 | 主要机械进退场；运输与起重适配；检验仪器及维保 | 区分施工机具和检测设备，列配置依据、台数、适用工序、使用窗口、共享冲突及核验 |
| 劳动力安排计划 | 分区分阶段工种；用工、产能和峰值；持证岗位、进退场与交接 | 按同一口径加总分工种人数和重叠作业人数，说明峰值时段、有效工日；管理岗位另列或注明计入 |
| 确保工程质量的技术组织措施 | 质量职责；材料复验；分项实测和停检；检验批、试验、整改和移交 | 对关键分项给出检查项目、方法、时点、范围或抽样依据、判据与记录 |
| 确保安全生产的技术组织措施 | 风险辨识及职责；逐类危大工程；临电、动火和交叉作业；应急及复工 | 逐类核对施工参数、专项方案及论证触发、验收、巡视或监测、停工与复工确认 |
| 确保工期的技术组织措施 | 施工分区和节点；关键线路与搭接；材料到货、资源和特定作业窗口；纠偏与移交 | 可由同一计划复核相对日、工期、紧前关系、图表、峰值、并行资源和验收等待 |
| 确保文明施工的技术组织措施 | 施工隔离与交通；噪声、扬尘、污水和垃圾；既有与新做成品保护；规定的现场管理配置 | 按现场影响对象列措施、检查岗位与频次、异常处置和恢复；有要求的监测或智慧工地功能按招标等级落地 |

## 二、从分部写到可实施的小节

1. 从清单分部和图纸开始。将同一工艺的清单项合并策划，保留做法、材质、部位或验收不同的代表项。招标指定专项、跨使用区域接口、风险较高的工序和有独立停检点的分项优先展开。先列部位与来源，再写工序，避免只照通用专业名称分章。
2. 关键方法写清**使用部位及其现状 → 开工条件和前置验收 → 分步做法和接口 → 检查时点、方法与依据 → 成品保护和转序条件**。按参考样本写法，每个三级工艺小节正文宜采用五段加粗引导语依序展开：**技术参数及工艺控制。**（部位、工程量、材料规格与设计参数）→ **施工方法及操作要点。**（前置条件、工艺流程与分步实操）→ **质量控制要点及验收标准。**（检查时点、方法、规范依据、合格判据与记录）→ **安全与环保注意事项。**（防护、临电、动火、扬尘噪声与清运）→ **关键控制点与异常处置。**（停检点、偏差阈值、暂停与恢复条件、转序签认）。对现场暂未核定的数据，给出需确认的对象、责任和放行条件，不从样本填入尺寸、范围或确认结果。
3. 用连续正文解释步骤、关键参数和措施依据。材料、用工、台班或验收指标需要横向对照时用原生表；不必把叙述写成表格。施工动作、空间关系、控制分支和时间依赖按 `visual-layout.md` 选图并就近放置。可无图、单图或多图，以是否补充必要信息为准。
4. 计划复核使用同一组经确认的数据：分区分项工程量、有效工作日/台班、拟用资源、起止和紧前关系。先按工程量与有效产能校核持续时间及用工，再检查同日重叠的人员、设备和工作面，最后核对采购、隐蔽验收、养护、调试与专项检测的前置关系。检查各阶段各工种合计是否等于阶段总人数，人员和场外岗位的统计口径一致。源数据不全时记录口径和缺口，遵循现有事实、资源确认规则。
5. 核实每个招标重难点在正文有对应位置，并能回指方法、资源与检查。例如，同层在用系统改造的小节应能查到保留对象、原状基线、审批窗口、预检、切换、异常恢复及复验人，而不只是写“加强协调”。围绕具体约束展开，常规施工术语和时限以项目可核实依据为准。

例如，既有在用楼层的吊顶封板依次写明三个施工环节。房间交付时，施工员复核原有设施边界和净高，按综合图协调风口、喷头和灯具。封板前，机电、消防和装饰核对本房间试验、封堵、检修空间与末端位置，签认允许封板的范围。发现点位冲突或试验未完成时，保持该房间可检查，由责任专业整改复验，下一道工序按已签认范围施工。项目具体部位、试验项目和量值从有效图纸、条款和样板取得。

## 三、全稿复核

先评施工分项是否拆到可执行、可验收，再查篇幅与版式。一个小节中存在几种独立做法、不同部位的验收判据或多套系统交接条件时，分别展开。以各项工程事实、实际施工安排和交验条件为编制依据，页数用作招标格式核验。

- 按目录核对所有评审项、招标指定专项和清单主要分部。逐节回查矩阵中已列的关键分项。去掉小节标题后，仍须能识别具体部位、实际步骤、工序接口、签认和转序。只有原则或概述的回原节补齐。质量控制点、验收表或示意图可以承载判据和记录，施工过程在对应小节写完整。
- 对照拟投入表、进度表、横道图及网络图，把关键资源、阶段用工、峰值、进度起止和紧前关系相互核对。总平面也要与运输和物资组织一致。
- 在 `analysis/visual-plan.md` 保留检查结论、页码或节图号以及待补项。页数少于上限时按资料和评审要点回查薄弱章节，剩余版面优先补现场图、节点、验收和计算依据。有余页且该写的都齐全时直接定稿。页数与字数以锁定格式和实际内容为准，无通用字数、图数或章数配额。
- 上述为人工技术复核。格式、篇幅、必要插图的落点和版本依照现有脚本校验，技术做法与现场真实性以人工核对为准。
