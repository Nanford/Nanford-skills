# 工程类招标法规与资格条件知识库

> 用途：编排**工程类**招标文件（流派 G 默认，或施工/装修/EPC/总承包）时，必须对照本库 + **实时检索**项目所在地主管部门规则，校正资格条件、评标办法、歧视性条款。
> 原则：**法律效力以正式发布文本为准**；本库是检查清单与检索入口，不是替代法规原文。生成前对项目所在省/市住建、财政、公共资源交易中心做一次检索核对。

## 一、必须过一遍的上位法（全国）

| 层级 | 文件 | 编排时关注点 |
|---|---|---|
| 法律 | 《招标投标法》《招标投标法实施条例》 | 依法必须招标范围、公告、评标委员会、否决投标、异议投诉 |
| 部门规章 | 《工程建设项目施工招标投标办法》（七部委 30 号令及修订） | 施工招标具备条件、资格预审/后审、招标文件组成 |
| 住建 | 《房屋建筑和市政基础设施工程施工招标投标管理办法》（建设部令第 89 号及修订） | 房建市政施工招标监管、资格、定标相关 |
| 发改等 | 《必须招标的工程项目规定》（发改规〔2018〕16 号）及配套解释 | 是否属于依法必须招标、规模标准 |
| 住建 | 《建筑工程施工发包与承包违法行为认定查处管理办法》等 | 转包挂靠、资质挂靠禁止表述 |
| 财政（政采工程） | 《政府采购法》《政府采购法实施条例》《政府采购货物和服务招标投标管理办法》（87 号令） | **仅当走政府采购程序时**适用；工程若适用招标投标法体系，勿混用 87 号令废标条款 |

### 施工招标启动条件（七部委办法要点，写入公告/须知时核对）

依法必须招标的施工项目，一般应同时满足：招标人已依法成立；初步设计及概算已获批（需审批的）；招标范围/方式/组织形式已核准（需核准的）；资金或资金来源已落实；有招标所需图纸及技术资料。

## 二、资格条件设置红线（工程类高频）

生成或改写“投标人资质条件”时，**禁止**下列歧视/不当条款（发现参考文件中有则标红并询问用户是否删除）：

1. 要求投标人在本地注册、设立分公司、本地缴纳社保/纳税作为准入或加分（营商环境禁令）。
2. 要求特定行政区域或特定行业的**唯一**业绩、奖项，变相指定潜在投标人。
3. 施工总承包资质范围内又叠加该范围内专业承包资质作为**同时必须**（排斥竞争）。
4. 将营业执照经营范围写死到不合理细项、与项目无关的证书捆绑。
5. 设定与项目规模明显不匹配的过高资质等级或过大类似业绩金额门槛（可能被认定为不合理条件）。
6. 要求购买指定品牌保险、指定检测机构等无法律依据的绑定。

### 资质设定合理惯例（须用户确认具体等级）

| 项目类型 | 常见资格维度（示例，非默认值） |
|---|---|
| 房建施工 | 建筑工程施工总承包相应等级 + 安全生产许可证 + 项目经理（注册建造师）专业与级别 + 安全生产考核合格 B 证 |
| 装修装饰 | 建筑装修装饰工程专业承包相应等级，或施工总承包（在承包范围内）+ 项目经理资格 |
| 设计施工总承包（EPC/DB） | 设计资质与施工资质双轨（或联合体分工）+ 设计负责人/项目总负责人资格；联合体协议与牵头人 |
| 市政/机电 | 对应专业承包或总承包资质 + 特种作业/专业人员（按工程内容） |

类似业绩：年限（常见近 3～5 年）、合同金额/规模、是否允许联合体成员业绩——**必须用户确认**，禁止照搬参考项目金额。

## 三、工程类招标文件内容模块（与流派 G 对齐）

国家标准施工招标文件/工程总承包招标文件常见组成（克隆时以用户参考文件为准）：

1. 招标公告（或投标邀请书）
2. 投标人须知及前附表
3. 评标办法（及前附表）
4. 合同条款及格式
5. 发包人要求（工程需求/设计任务书/技术标准）
6. 发包人提供的资料（地质、图纸清单等）
7. 投标文件格式

工程特有槽位（须标红确认）：建设地点、招标范围、计划工期、质量标准、最高投标限价（可拆设计费/建安费）、成本警示价/控制价下浮、是否接受联合体、分包规定、履约担保比例与形式、电子招投标平台名称、定标办法（票决/得分排序等）。

## 四、地域规则检索清单（成稿前必查）

编排工程标时，根据**项目所在地**检索并摘录要点（写入中间稿备注或资格章“法规依据”）：

| 层级 | 检索入口（示例） | 查什么 |
|---|---|---|
| 国家住建部 | `www.mohurd.gov.cn` | 施工/EPC 招标监管、资质标准、禁止性规定 |
| 国家财政部 | `www.mof.gov.cn` | 仅政采工程：采购方式、中小企业、保证金 |
| 国家发改委 | `www.ndrc.gov.cn` | 必须招标范围、电子招标投标办法 |
| 省住建厅 | 如 `zfcxjst.gd.gov.cn`（广东） | 房建市政招标细则、评标办法、信用信息 |
| 省财政厅 / 政采网 | 如 `gdgpo.czt.gd.gov.cn`（广东政采） | 政采云平台字段、公开招标范本 |
| 市住建 / 公共资源交易中心 | 项目所在市交易中心门户 | 电子标操作、保证金账户、公告媒介、否决条款口径 |
| 中国招标投标公共服务平台 | `www.cebpubservice.com` | 公告发布媒介表述 |

### 广东省工程类（与两份新模板相关）注意点

- 房建市政施工/总承包多走**公共资源交易中心电子标**（如广州交易集团数字交易平台），用语是“招标人/投标人/中标人”，适用招标投标法体系。
- 政府采购云平台模板（流派 H）走**广东省政府采购智慧云平台**，用语是“采购人/供应商/中标供应商”，适用政府采购法体系——**工程内容若挂政采程序，资格与废标条款按政采写，勿混用施工总承包范本废标句式。**
- 广州地区常见：穗府办函关于投标保证金减免/承诺制等政策——以项目当期有效文件为准，参考文件有“免收保证金+承诺”时须请用户确认是否仍适用。

## 五、技能执行动作（写入 SKILL 流程）

工程类项目在阶段一解析完成后、阶段二资格采集前：

1. 确认项目所在地（省/市）与程序类型（招标投标法工程 **vs** 政府采购）。
2. 检索：`{省} 房屋建筑 市政 招标投标 管理` + `{市} 公共资源交易 投标人资格` + 住建部/财政部相关禁令。
3. 输出《法规核对摘要》给用户（不超过 15 条要点）：法定招标条件、资格红线、保证金政策、评标定标地方特殊规定。
4. 用户确认后再写入资格条件与废标项；冲突时以**用户确认的地方现行有效文件**为准，参考文件旧条款标红待改。

## 六、与废标库的衔接

- 工程招标投标法项目：废标/否决以参考文件 + 《实施条例》中串通投标、弄虚作假等为准；`rejection-library.md` 中政采表述需改写为“否决投标”。
- 政采云平台项目：保留 87 号令及省平台“资格性/符合性/★条款”结构。
- 两种程序**不得混用**同一套废标默认句。
