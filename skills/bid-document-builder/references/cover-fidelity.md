# 封面保真规范

## 决策顺序

1. 有 `.doc/.docx` 主参考：参考首页是唯一设计权威，克隆首页全部 OOXML 元素与关系，只替换已确认字段。
2. 只有 PDF：记录首页视觉特征；当前生成器不能可靠克隆可编辑 PDF 封面，使用默认封面并声明降级。
3. 没有参考：使用默认 A4 中文标书封面。

## 必检属性

- 页面：纸张、方向、页边距、装订线、页眉页脚距离、首页不同设置。
- 段落：字体、字号、粗斜体、颜色、字间距、行距、段前后、对齐、左右/首行/悬挂缩进。
- 图片与图形：类型、尺寸、纵横比、裁剪、行内/浮动、锚点、相对位置、环绕方式。
- 结构：表格、文本框、形状、空白段、封面结束边界、显式或自然分页。
- 首页家具：首页页眉、页脚、页码、横线、水印是否存在。

## 字段替换

优先使用 `cover_data.json` 语义键：`document_title`、`project_code`、`project_name`、`issuer`、`date`。参考封面使用其他槽位时，可在 JSON 中直接增加 `"参考旧值": "新值"`；生成器只在封面范围内等值替换。

不得把未确认值写死。未命中或未确认的参考占位保留到成稿，并列入人工终审。

## 渲染门禁

参考首页和成稿首页都要真实渲染并逐项并排检查。Word/WPS 固定版式导出或 LibreOffice 均可；没有渲染工具时只做结构属性校验，并明确说明未完成视觉验证。
