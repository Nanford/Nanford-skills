# 废标项（否决投标）与资格文件默认库

> 用途：阶段二向用户展示的默认勾选清单。**废标项必须由用户逐条确认（保留/删除/修改），不得由 AI 擅自定稿**。
> 来源：15 份参考招标文件中出现频次 ≥3 的条目归纳。

## 一、废标项默认库（按审查阶段分组）

### A. 资格审查阶段（一项不符即否决）
| # | 条目 | 默认建议 |
|---|---|---|
| A1 | 不具备有效营业执照，或经营范围不含本项目内容 | 保留 |
| A2 | 未提供法定代表人身份证明或授权委托书，或授权无效 | 保留 |
| A3 | 财务状况不满足要求（未提供审计报告/资信证明） | 保留 |
| A4 | 未提供依法缴纳税收和社会保障资金的证明 | 保留 |
| A5 | 被"信用中国"列为失信被执行人、重大税收违法案件当事人，或列入政府采购严重违法失信行为记录名单 | 保留 |
| A6 | 不满足招标文件规定的特定资格要求（业绩/资质/认证） | 按项目填写具体资质后保留 |
| A7 | 单位负责人为同一人或存在控股、管理关系的不同单位参加同一合同包投标 | 保留 |
| A8 | 与招标人存在利害关系且可能影响招标公正性 | 保留 |

### B. 符合性审查阶段（一项不符即否决）
| # | 条目 | 默认建议 |
|---|---|---|
| B1 | 投标文件未按要求签字、盖章（含电子签章/CA 签章） | 保留 |
| B2 | 投标有效期不足招标文件规定（常见 90 日历日） | 保留，天数待用户确认 |
| B3 | 未按规定金额、形式、时间缴纳投标保证金或未按时到账 | 保留，金额与账户待用户确认 |
| B4 | 投标报价超过最高限价（或采购预算） | 保留，限价待用户确认 |
| B5 | 同一合同包提交两个以上不同投标文件或报价（可选择性报价） | 保留 |
| B6 | 未对合同包内全部内容进行完整投标 | 保留 |
| B7 | 任一 ★ 号条款（参数）负偏离 | 保留 |
| B8 | ▲ 号条款负偏离项数超过允许上限（默认 10 项，待确认） | 保留，上限待用户确认 |
| B9 | 一般条款负偏离项数超过允许上限（默认 15 项，待确认） | 保留，上限待用户确认 |
| B10 | 分阶段评审时，价格内容出现在开标一览表/价格分册之外 | 仅电子平台分阶段评审项目保留 |
| B11 | 投标文件含有招标人不能接受的附加条件 | 保留 |

### C. 评标过程阶段
| # | 条目 | 默认建议 |
|---|---|---|
| C1 | 串通投标（协商报价/约定中标人/约定放弃/同组织协同/其他联合行动） | 保留 |
| C2 | 视为串通投标（文件错漏一致、同一单位编制、同一人缴社保、混装文件、保证金同户转出、同一 IP/MAC/加密锁） | 保留 |
| C3 | 弄虚作假、提供虚假材料谋取中标 | 保留 |
| C4 | 向招标人或评标委员会成员行贿 | 保留 |
| C5 | 不按评标委员会要求澄清、说明或补正 | 保留 |
| C6 | 联合体各方再以自己名义单独投标或参加其他联合体投标 | 接受联合体时保留，否则删除 |
| C7 | 一个制造商对同一品牌同一型号产品委托两个以上代理商投标 | 允许代理商投标时保留 |

## 二、关键资格文件默认清单

**一般资格（所有项目）**：
1. 营业执照副本复印件（加盖公章）
2. 法定代表人身份证明 及 法人授权委托书（附身份证）
3. 近 1~3 年经审计的财务报告 或 银行资信证明（年限待用户确认）
4. 近 6 个月依法缴纳税收和社会保障资金的证明
5. 参加招标活动前三年内无重大违法记录的书面声明
6. "信用中国"(www.creditchina.gov.cn) 及 中国执行信息公开网 (zxgk.court.gov.cn) 查询结果截图

**特定资格（须用户逐项确认）**：
- 类似项目业绩（数量、年限、金额门槛、关键词界定——须用户提供）
- 行业资质/体系认证（ISO9001/20000/27001、ITSS、CCC、建筑智能化、安防等）
- 制造商授权书（代理商投标时）
- 拟派项目经理及团队资格（PMP/软考等级、社保要求）

## 三、★/▲ 符号分级决策规则（供起草时向用户建议）

| 判断 | 建议分级 |
|---|---|
| 不满足则项目无法运行/验收（核心功能、法定强制标准、交期红线、总价合同形式） | ★ |
| 关键性能指标，可量化、可用证明材料佐证（分辨率、精度、点位数、寿命等） | ▲ |
| 期望型/加分型要求 | 一般条款 |

注意：★ 条款数量不宜过多（参考文件中一般 5~15 条），过多易造成围标质疑或全场废标；每一条 ★/▲ 都必须能被客观判定，禁止"原则上""尽量"类模糊措辞。**最终分级由用户逐条确认。**
