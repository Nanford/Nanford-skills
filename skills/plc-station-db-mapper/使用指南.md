# PLC站台DB点位映射 Skill 使用指南

## 1. 定位
本 skill 用于将各种格式的 PLC 点位原始数据，标准化并批量生成站台点位表。支持 4 种输入方式，交互式引导选择。

## 2. 使用方式

调用 skill 后，会先询问你的输入类型：

```
请选择你本次提供的原始点位格式：

1. DB截图 — TIA Portal 中 DB 块的截图
2. 导出PDF — TIA Portal 导出的 DB 定义 PDF
3. 导出XLSX — TIA Portal 导出的变量表 Excel
4. 手动输入 — 直接给出点位列表、偏移量和结构
```

然后根据选择走不同的处理路径。

## 3. 四种输入类型说明

### 类型 1：DB截图
- 适用：TIA Portal 中 DB 块编辑器的截图（PNG/JPG）
- 示例：reference/DB50.png、reference/DB70.png
- 特点：截图中通常能看到 Struct 定义，可以直接计算 stride，**只需 1 个站台**
- 需要提供：DB 号、基准站台号、类别、目标站台范围

### 类型 2：导出 PDF
- 适用：从 TIA Portal 导出的 DB 定义 PDF
- 示例：reference/堆垛机DDJ_Data (DB142).pdf
- 特点：可能包含多页，需逐页识别
- 需要提供：同类型 1

### 类型 3：导出 XLSX
- 适用：TIA Portal 导出的变量表 Excel
- 示例：reference/原料库南D02变量表.xlsx
- 特点：会自动检测地址格式并分流
  - DB 地址 → 走 stride 流程
  - %I/%Q/%M 地址 → 直接标准化，不做站台推算
  - 纯偏移 → 需要提供 DB 号

### 类型 4：手动输入
- 适用：已经知道点位信息，直接以文字或表格形式提供
- 需要提供：基准站台点位列表、stride、目标站台范围、类别

## 5. 关键说明
- 每个项目的 stride 不同，不可套用历史值。
- Struct 大小 = stride，是最可靠的推算方式。
- %I/%Q/%M 地址不遵循站台化模式，不能做 stride 推算。
- 输出的 Excel 可直接导入 OPC UA 数采系统。

## 6. 常见问题
- **只有 1 个站台的数据怎么办？**
  → 如果有 Struct 定义（截图/PDF 中可见），可以直接计算 stride。否则需要手动指定。
- **地址是 %I/%Q 格式**
  → 这些是 I/O 点位，不需要做站台化推算，直接标准化即可。
- **遇到 Real/Float 类型报错**
  → 已支持。Real/Float 使用 D (DWord) 地址，占 4 字节。
